進度存在哪裡

你的進度（打勾、說過、20 遍、小驗收）只存在這支手機的瀏覽器裡，沒有上傳到任何地方。換手機、或清除網站資料，進度就會消失。
  • iPhone：請先在 Safari 按「分享」→「加入主畫面」，從主畫面圖示打開使用。沒有安裝的網頁，Safari 一陣子沒開就可能把資料清掉。
  • 每週日按下面的「匯出進度」，貼給 Claude，Claude 幫你勾進 1000 單與語塊表，也等於幫進度留一份備份。

匯入進度

換手機或不小心清掉時用。把先前匯出的整段文字貼進來，會先預覽，確認後才合併；比較新的進度不會被舊的蓋掉。

Azure 語音（選填）

key 只存在這支手機，不會進匯出的進度、也不會放進網頁程式。只有按播放時，才會把要唸的那句和 key 直接傳給 Microsoft Azure 換聲音。
還沒有設定。

播放順序：有填 key 先用 Azure；Azure 不能用就放預錄的 Aria 音檔；還是不行就用手機內建的英文語音。預錄的 440 句本來就是 Azure 的 Aria 嗓音，所以不填 key 也一樣好聽。填了 key 的好處：任何新句子都能唸、可以換嗓音和語速。Azure 免費額度大約每月 50 萬字，實際方案請到 Azure 後台自己確認。
